# 🐾 PetMania

Projeto acadêmico desenvolvido com o objetivo de corrigir e aprimorar o código de um sistema de pet shop, garantindo o funcionamento da API responsável pelo cadastro de animais.

## 📌 Sobre o projeto

O PetMania é um sistema de pet shop que permite realizar o cadastro de animais por meio de uma API, integrando o backend à interface do site.

A atividade teve como principal objetivo identificar e corrigir problemas existentes no código, implementar o funcionamento da API de cadastro de animais e permitir o armazenamento de imagens dos animais cadastrados.

## 🚀 Funcionalidades desenvolvidas

- Correção de erros no código original.
- Implementação e funcionamento da API de cadastro de animais.
- Integração entre a API e o site.
- Cadastro de informações dos animais.
- Armazenamento de imagens dos animais.
- Testes de requisições utilizando o Postman.

## 🛠️ Tecnologias utilizadas

- Java
- Spring Boot
- API REST
- Postman
- Banco de dados
